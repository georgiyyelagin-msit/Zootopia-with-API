# MSIT Zootopia with APIs

This project deals with the assignment of getting animals infos using animals API and users input

## Installation

To install this project, simply clone the repository and install the dependencies in requirements.txt using `pip`

## Usage

To use this project, run the following command - `python animals_web_generator.py`.
you will be prompted to enter animal for which you'd like to request infos from the animal api
if infos were fetched, the animals.html will contain the list of results
